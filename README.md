# DevSeed

**Database Seed Data Generator**

DevSeed is a browser-based tool that helps developers quickly generate realistic test data and SQL seed statements for development databases.

## 🎯 Purpose

Creating test data manually can be repetitive and time-consuming. DevSeed aims to make the process faster by allowing developers to define a database table and generate realistic sample records automatically.

## 🛠️ Technology

* HTML
* CSS
* Vanilla JavaScript

## ✨ Planned Features

* Define database fields
* Generate realistic test data
* Generate SQL `INSERT` statements
* Choose the number of records
* Copy generated SQL
* Download generated `.sql` files
* No account required
* Runs directly in the browser

## 🚧 Status

**Early development — MVP**

The first version is being developed as a small, browser-based MVP.

## 🎯 Goal

Build and publish a useful developer utility while keeping the first version simple, fast, and easy to use.
